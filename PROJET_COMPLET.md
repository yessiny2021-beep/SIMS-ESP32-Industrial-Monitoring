## 📱 Quick Reference

### Commandes Serial Essentielles
```bash
MENU          # Afficher le menu
STATUS        # État du système
SETTEMP 35    # Température max = 35°C
SETHUM 80     # Humidité max = 80%
SETGAS 2500   # Gaz max = 2500
SETLIGHT 300  # Lumière min = 300
RESET         # Réinitialiser aux valeurs par défaut
```

### Seuils par Défaut
- 🌡️ Température max: **30°C**
- 💧 Humidité max: **70%**
- ☁️ Gaz max: **2000**
- 💡 Luminosité min: **500**

### Pins ESP32
```
GPIO15 → DHT22 (DATA)
GPIO34 → MQ2 (Analog)
GPIO35 → LDR (Analog)
GPIO21 → LCD (SDA)
GPIO22 → LCD (SCL)
GPIO25 → Buzzer
GPIO26 → LED Rouge
GPIO27 → Relais
GPIO2  → LED Bleue
```
